# ☢️ Бункер онлайн

Игра «Бункер» для друзей: комнаты по трёхзначному коду, без регистрации. Без зависимостей, нужен только Node.js 18+.

## Запуск локально
```
node server.js
```
Откройте http://localhost:3000

## Публикация (бесплатно)
1. Создайте репозиторий на github.com и загрузите в него все файлы этого проекта (кнопка *Add file → Upload files*).
2. Зайдите на render.com и войдите через GitHub.
3. *New → Web Service* и выберите ваш репозиторий. Если Render найдёт `render.yaml`, настройки подтянутся сами. Иначе укажите вручную: Runtime — Node, Build Command — пусто, Start Command — `node server.js`, план — Free.
4. После деплоя Render выдаст постоянную ссылку вида `https://bunker-game.onrender.com`. Её можно отправлять друзьям.

## Важно
- На бесплатном тарифе сервис засыпает после ~15 минут без посетителей, первое открытие после сна занимает около минуты. Комнаты живут в памяти и пропадают при перезапуске.
- На телефоне: откройте ссылку в Chrome → меню → «Добавить на главный экран».
